## ✨ Proje Hakkında

Fymension, dijital ajans hizmetlerini sergileyen modern ve animasyonlu bir portfolyo sitesidir. GSAP ile zengin geçiş efektleri ve modern UI tasarımı içerir.

## 🛠️ Kullanılan Teknolojiler

- **GSAP** — Sayfa geçiş animasyonları
- **Modern UI** — Temiz ve minimal tasarım
- **Responsive** — Mobil uyumlu
